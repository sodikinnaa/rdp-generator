Title (maks 100 karakter):
RDP Generator - Windows Server di GitHub Codespaces + Tailscale (Tanpa VPS)

Description:
-----------------------------------------------------------------
Butuh Windows / RDP tapi tidak mau bayar VPS bulanan?

RDP Generator adalah aplikasi 1 file (single binary) dengan dashboard
web modern untuk membuat Windows Server (2019 / 2022 / 2025) atau
Windows 11 Pro langsung di GitHub Codespaces, lalu diakses via Remote
Desktop dengan aman lewat Tailscale VPN.

YANG KAMU DAPAT
- Panduan akses + kumpulan link lengkap (file TXT/PDF)
- File aplikasi RDP Generator (Windows .exe / Linux / macOS)
- Panduan step-by-step: buat token, auth key, deploy, login RDP
- Tips hemat kuota Codespaces (120 core-hours gratis per bulan)
- Update gratis selama produk tersedia

KEUNGGULAN
- Tanpa VPS, tanpa kartu kredit khusus hosting
- Zero public port: RDP (3389) & noVNC (8006) hanya lewat Tailscale
- Hardware virtualization (KVM) -> Windows jalan lebih ngebut
- Disk Windows tersimpan permanen, bisa resume setelah restart
- Rahasia (Tailscale key) dienkripsi sebelum dikirim ke GitHub
- Cocok untuk: belajar Windows Server, lab testing, akses Windows dari
  HP/Mac/Linux, project sementara

KEBUTUHAN
- Akun GitHub (gratis) + Personal Access Token (scope: codespace)
- Akun Tailscale (gratis) + Auth Key
- Laptop/PC/HP dengan aplikasi Remote Desktop
- Internet stabil

BELUM BISA INSTALL SENDIRI?
Pilih add-on "Sesi Zoom Instalasi" (Rp 75.000) - dipandu langsung
sampai Windows kamu bisa di-RDP.

CATATAN PENTING
- Produk digital: file dikirim otomatis setelah pembayaran.
- Kuota Codespaces mengikuti aturan GitHub (akun Free: 120
  core-hours + 15 GB storage / bulan). Mesin 4-core = 4 core-hours
  per jam.
- Windows yang dipakai adalah versi Evaluation resmi Microsoft.
- Gunakan hanya untuk keperluan legal dan sesuai Terms of Service
  GitHub, Tailscale, dan Microsoft.
