Arsitektur Modern, Tanpa Beban Database

Seluruh state diturunkan secara deterministik dari akun GitHub Anda.

4 Core • 16 GB RAM

Dijalankan di infrastruktur GitHub Codespaces dengan passthrough KVM perangkat keras aktif untuk performa responsif tanpa emulasi software yang lambat.

Layar Browser noVNC

Langsung kendalikan desktop Windows dari browser Anda melalui port 8006 tanpa perlu mengunduh client RDP tambahan di komputer kerja Anda.

Tailscale MagicDNS

Koneksi RDP aman menggunakan nama host deterministik winlab-<nama>:3389 melalui jaringan WireGuard privat Anda.

100% Stateless (Tanpa DB)

Tidak ada database SQLite di controller. Kredensial disimpan di localStorage browser hingga direset, dan password diturunkan via WebCrypto HMAC-SHA256.

Single Go Binary

Satu binary ringkas tanpa runtime eksternal. Semua template HTML dan aset tersemat rapi di dalam binary Go yang dapat dikompilasi lintas sistem operasi.

Pilihan Versi Windows

Mendukung Windows Server 2022 (paling stabil & efisien), Windows Server 2019, Windows Server 2025, hingga edisi Windows 11 desktop.

Bagaimana Cara Kerjanya?

Alur sederhana dari klik tombol sampai layar Windows muncul.

01 / DASHBOARD

Anda memasukkan PAT GitHub, Tailscale Key, dan Master Secret di browser.

02 / PROVISIONING

Controller membuat Codespace dengan secret aman (RDP_MASTER_SECRET, TS_AUTHKEY).

03 / BOOTSTRAP

Codespace menjalankan QEMU KVM Windows dalam Docker dan bergabung ke Tailnet Anda.

04 / KONEKSI

Buka via link noVNC browser atau sambungkan client RDP ke winlab-<nama>:3389.

Mulai Dalam Tiga Langkah

Jalankan secara lokal di laptop atau server Anda sendiri.

1

Jalankan Binary Hasil Unduhan

Pada Windows, klik dua kali file .exe hasil unduhan. Untuk macOS dan Linux, ekstrak arsip lalu jalankan dari terminal:

chmod +x ./rdp-generator-linux-amd64
./rdp-generator-linux-amd64 -port 8787 -open

Ingin membangun dari sumber? Jalankan go run main.go -port 8787 setelah mengkloning repositori.

2

Buka Dashboard & Masukkan Pengaturan

Buka http://localhost:8787/dashboard. Masukkan GitHub PAT dengan scope codespace, Tailscale Auth Key, dan tentukan Master Secret (minimal 32 karakter).

3

Klik Buat Mesin & Langsung Pakai

Pilih versi Windows dan klik Buat. Setelah Codespace aktif, klik tombol buka layar di browser atau hubungkan Remmina/MSTSC ke hostname MagicDNS.
